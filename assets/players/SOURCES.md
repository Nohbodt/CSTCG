# Temporary player photo sources

Alpha 0.5.1 installs 25 real-player photos from the public collections below. These are temporary source photos, with their original jerseys; the user requested available headshots now and a later revision. No photographic likenesses were generated. Photographic rights remain with their original owners; the source repositories’ code licenses are not treated as licenses for the photographs.

The JSON manifest beside this file records pinned revisions, original source/profile URLs, file hashes and changes for each installed image. The 24 profile portraits from Xocks preserve the upstream WebP bytes and were matched by handle, full name and HLTV profile ID. The additional broky photo preserves the supplied JPEG and PGL watermark. These files are local game assets; play never downloads portraits.

Missing in this pass: syrsoN, RUSH, ALEX (Alex McMeekin), interz and F1KU. Those cards retain neutral monograms. A different professional named alex in another collection was excluded.
