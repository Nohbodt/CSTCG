# Series 1 art direction boards

`pack-family.png` and `card-direction.png` are generated visual references for the selected layout/material direction. They demonstrate the four product identities and base/Showcase/Event card treatments. The portraits are generated illustrations, not sourced photographs or player endorsements.

The source of truth for spellings, stats, global numbers, rarity and membership is `../series1_manifest.json`. Final game text is rendered from that data in separate layers; generated small lettering is reference artwork and must not become a baked production label. The vector proofs provide accurate text and geometry for that handoff.
